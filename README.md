# Rainy Days - Online Outdoor Store
Rainy Days is a responsive e-commerce website developed as part of the HTML and CSS course at Noroff. The project focuses on building a user-friendly online store for browsing and purchasing outdoor clothing and equipment.

## Description
The goal of this project was to create an online shopping experience with a clear layout, consistent styling, and intuitive navigation. Visitors can explore the product range, view individual product details, select sizes, review their shopping cart, and proceed through a checkout flow.

The website was built using HTML and CSS, with an emphasis on responsive layouts and reusable design elements.

## Pages
The project consists of seven pages:
- Home: Introduces the store and highlights featured products, offers, FAQs, and customer reviews.
- Products: Displays the available product selection.
- Product Details: Presens information about an individual product, including size options.
- Shopping Cart: Shows selected items before checkout.
- Checkout: Provides a form for entering order information and reviewing the purchase.
- Order Confirmation: Displays a confirmation message after an order is submitted.
- Under Construction: A placeholder page for content that has not yet been implemented.

## Key Features
- Responsive layouts for mobile, tablet, and desktop screens.
- Navigation designed to make the website easy to explore.
- Product listings and individual product information.
- Consistent buttons, product cards, and call-to-action sections.
- Forms for user input during the shopping process.
- Shopping cart and checkout page layouts.
- Newlestter sign-up section.

## Run the Project Locally

### Requirements
You will need Git, a code editor such as Visual Studio Code, and a web browser.

### Setup

1. Clone the repository:

```bash
git clone https://github.com/LinxonXD/html-css-sindre-kristiansen.git
```

2. Navigate to the project directory:

```
cd html-css-sindre-kristiansen
```

3. Open the folder in Visual Studio Code

4. Install or enable the Live Server Extension, then launch index.html using Open with Live Server.

5. Open the local addess provided by Live Server in your browser. The port may vary depending on your configuration.
